YouTube の基準は約 -14 LUFS。歌枠は -16〜-14 が目安。
使い方（クイックスタート）
  1. Chrome / Edge で開き「エンジン起動」。マイクを選び、入力チャンネル（IN1/IN2）を合わせる
  2. YouTube のカラオケ動画を別タブで開き「YouTubeタブを取り込む」→ そのタブを選択し「タブの音声も共有する」をオン（タブ側のスピーカー音は自動で止まります）
  3. モニター出力にイヤホン、配信出力に仮想デバイス（VB-CABLE 等）を指定。OBS ではその仮想デバイスを音声入力に追加（デスクトップ音声は切る）
  4. 「自動推定」で遅延補正を入れ、録音ボタンで一度録って声と伴奏のズレを確認
  5. 曲調に合わせて 1〜6 でシーン切替。MC の間は 6（MC / トーク）
