# 筋トレ記録（エビデンスベース増量アプリ）

React + Vite + Tailwind + Firebase（Auth / Firestore）の PWA。ジムで1セット10秒以内に入力し、
週セット数（0.5換算）・RIR・体重7日平均・kcal／タンパク質を集計して、週次JSONを Claude に貼ってレビューする。

## 使い方

```bash
npm install
npm run dev      # 開発サーバー
npm test         # 計算ロジックのテスト
npm run build    # dist/ に PWA をビルド
```

Firebase を設定しなければ **ローカルモード**（端末の localStorage に保存）で動きます。
すぐ試せますが、機種変更に備えて設定画面の「全データJSON」で定期的にバックアップしてください。

## Firebase の設定（無料枠で動作）

1. [Firebase コンソール](https://console.firebase.google.com/)でプロジェクトを作成
2. Authentication → Google ログインを有効化
3. Firestore Database を作成し、`firestore.rules` の内容をルールに設定（自分の `users/{uid}` だけ読み書き可）
4. プロジェクトの設定 → ウェブアプリを追加し、値を `.env.example` を参考に `.env.local` へ
5. `npm run build && npx firebase-tools deploy`（Hosting と Firestore ルール）
6. スマホで開いて「ホーム画面に追加」

Firestore はオフライン永続化を有効にしているので、電波の弱いジムでも記録でき、復帰後に自動同期されます。
トレーニングは完了時に1セッション＝1回の書き込みで保存します（入力中は端末内の下書き）。

## 画面

| 画面 | 内容 |
| --- | --- |
| ホーム | 次のメニュー（A/B交互）、今日の kcal・P の残り、朝の体重と7日平均・先週比、ディロード提案 |
| トレーニング | 前回値をプリセット、±で修正、**RIRボタンをタップでセット完了**＋休息タイマー自動開始。上限達成で「次回は重量アップ」、1部位11セット超で警告、停滞・低下の表示、種目差し替え |
| 食事 | マイ食品ワンタップ加算（よく使う順）、直接入力、目標との差、メモ |
| 進捗 | 体重（日次＋7日平均）、維持カロリー推定→目標kcalに反映、部位別週セット数（10〜20の帯で色分け、RIR4+は別表示）、推定1RM推移、周囲径、履歴 |
| 設定 | 週次レビューJSON（コピー／DL）、レビュー用プロンプト、目標値、プログラム編集（週セット数の見込み表示）、種目マスタ、CSV／バックアップ／復元 |

## 主な計算（`src/lib/calc.js`）

- 週セット数：主部位1・補助部位0.5（fractional）。ウォームアップ除外、RIR4以上は別集計
- 強度：開始1〜2週目は RIR3、以降は多関節 RIR1〜2・単関節 RIR0〜1
- ダブルプログレッション：計画セット数すべてでレップ上限に届いたら、次回は種目ごとの刻みで重量アップ（回数は下限から）
- 停滞：推定1RMが2回連続で伸びない → 週セット+1〜2を提案／3回連続低下 → ディロード提案（どちらも経験則）
- 推定1RM：Epley式 `重量 × (1 + 回数 ÷ 30)`
- 維持カロリー：直近21日の平均摂取 −（7日平均体重の変化 × 7700 ÷ 日数）
